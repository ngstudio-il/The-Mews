# The Mews – תוסף וורדפרס לדף הנחיתה

התוסף מתקין את דף הנחיתה של The Mews Residences בכל אתר וורדפרס, עם כל התוכן ניתן לעריכה לפי אזורים, בעברית ובאנגלית.

## התקנה
1. בלוח הבקרה: **תוספים ← הוספת חדש ← העלאת תוסף**, ובוחרים את `the-mews-landing.zip`.
2. לוחצים **הפעלה**. התוסף יוצר שלושה עמודים: דף הנחיתה (`/the-mews/`), מדיניות פרטיות (`/privacy/`) והצהרת נגישות (`/accessibility/`).
3. כדי שדף הנחיתה יהיה דף הבית: **הגדרות ← קריאה ← עמוד בית סטטי**, ובוחרים "The Mews Residences".

> אם ההעלאה נכשלת בגלל גודל הקובץ (כ-13MB, בגלל הסרטונים), מבקשים מחברת האחסון להגדיל את `upload_max_filesize`, או מעלים את התיקייה `the-mews-landing` ב-FTP אל `wp-content/plugins`.

## עריכה
בתפריט הצד: **The Mews ← עריכת תוכן**. כל לשונית היא אזור בדף:
הגדרות כלליות · תפריט עליון · פתיח · פס נתונים · הפרויקט · למה דווקא · גלריה · מיקום · שאלות נפוצות · אזור תחתון · טפסים · פוטר.

- כל שדה טקסט מופיע פעמיים: עברית מימין ואנגלית משמאל. כפתור EN בדף מחליף לאנגלית.
- רשימות (נתונים, כרטיסים, גלריה, מרחקים, שאלות): מוסיפים, מסירים וגוררים לשינוי סדר.
- תמונות וסרטונים נבחרים מספריית המדיה.
- "שחזור ברירת מחדל ללשונית" מחזיר את הלשונית לתוכן המקורי.

עמודי מדיניות הפרטיות והצהרת הנגישות נערכים בעורך הרגיל של וורדפרס (עמודים). השדות המסומנים בצהוב צריך להשלים.

## לידים
- כל פנייה מהטופס נשמרת ב-**The Mews ← לידים**, עם כפתור ייצוא ל-CSV.
- כל ליד נשלח גם למייל שמוגדר בלשונית "הגדרות כלליות" (ריק = מייל מנהל האתר). מומלץ תוסף SMTP כדי שהמיילים לא יגיעו לספאם.
- אפשר להגדיר Webhook שיקבל כל ליד (CRM, Zapier, Make).
- הגנה מספאם: שדה נסתר לבוטים, ומגבלה של 5 פניות ל-10 דקות מאותה כתובת.

## עבודה על הקוד
הקבצים המשותפים (CSS, JS, תמונות, סרטונים) נמצאים ב-`assets/` של האתר הסטטי. כדי לבנות את קובץ ה-zip:

```
wordpress/build.sh   # -> wordpress/dist/the-mews-landing.zip
```

## עריכה מרחוק (API)
מגרסה 1.1.0 יש לתוסף API מאובטח לעריכת התוכן, למשל דרך Claude:

- `GET /wp-json/tml/v1/content`: כל התוכן לפי אזורים.
- `POST /wp-json/tml/v1/content`: עדכון השדות שנשלחו בלבד, לדוגמה `{"hero": {"l2": {"he": "...", "en": "..."}}}`.
- `POST /wp-json/tml/v1/content` עם `{"__reset": "hero"}`: החזרת אזור לברירת המחדל.

הגישה מותרת רק למנהלי אתר, עם סיסמת אפליקציה (משתמשים ← פרופיל ← Application Passwords) ובחיבור HTTPS.
